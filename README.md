# Sistema de Gestión Académica en Java

*TEMA:
Aplicación de consola desarrollada en Java para realizacion de un CRUD para estudiantes y docentes.

*Intruccion de la actividad:
Organización del sistema mediante clases y objetos.

*Herencia: 
Las clases estudiante y docente heredan de persona.

*Encapsulamiento: 
Uso de atributos privados con getters y setters.

*Constructores: 
Inicialización de objetos al crearlos.

*@Override: 
Sobrescritura del método mostrarDatos().

*ArrayList:
Almacenamiento dinámico de registros.

*CRUD:  
Permite crear, leer, actualizar y eliminar registros.

*Validaciones: 
Control de errores para evitar fallos del sistema.

*Funcionalidades
- Registrar personas  
- Mostrar registros  
- Actualizar datos  
- Eliminar registros  
- Menú interactivo
